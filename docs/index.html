Abstract

Raymarching is a category of rendering methods for 3D computer graphics that achieves the same purpose as its more popular counterpart, raytracing. But unlike raytracing, raymarching is traversed iteratively, decreasing in segment size for every step. However, this can become very expensive, mainly when each ray corresponds to each pixel drawn on the screen. The purpose of this project is to optimize this algorithm to know ahead of time whether our ray will traverse to the very size limit or if the ray will potentially hit a surface.
